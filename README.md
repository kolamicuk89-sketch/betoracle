# BetOracle — «Оракул спора»

Приложение .NET MAUI (C#), собранное и установленное на iPhone **без Mac**.

Шар предсказаний: задай вопрос, тряси телефон (акселерометр) или нажми кнопку — получишь ответ.

## Как это собирается

1. Windows 11 + Visual Studio 2026 — написание кода.
2. GitHub Actions — сборка unsigned IPA на облачном macOS-раннере (`.github/workflows/build-ios.yml`).
3. Sideloadly — подписка бесплатным Apple ID и установка на iPhone по USB.

Подпись живёт 7 дней (лимиты бесплатного Apple ID) — этого достаточно для демонстрации.
